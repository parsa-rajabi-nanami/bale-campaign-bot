# Code of Conduct

We want participation to be respectful, useful, and safe for everyone.

Examples of expected behavior include clear and considerate technical discussion, accepting constructive review, and focusing on the work. Harassment, discrimination, threats, doxxing, and deliberately disruptive behavior are not acceptable.

Project maintainers may remove content or restrict participation when needed to protect the community. Report conduct concerns privately to the maintainers through their GitHub profile contact. This project follows the spirit of the Contributor Covenant, adapted for this repository.
